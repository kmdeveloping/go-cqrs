# Handler Registry Generator

A code generation tool for automatically creating handler registration code for the go-cqrs framework.

## Purpose

This tool automatically scans your project for CQRS handlers and generates a `registry_gen.go` file with the appropriate registration calls. It supports:

- **Command Handlers** (structs ending with `CommandHandler`)
- **Query Handlers** (structs ending with `QueryHandler`) 
- **Event Handlers** (structs ending with `EventHandler`)
- **Validators** (structs ending with `Validator`)

## Installation

### Install globally via go install:
```bash
go install github.com/kmdeveloping/go-cqrs/tools/gen-handler-registry@latest
```

### Install from source:
```bash
git clone https://github.com/kmdeveloping/go-cqrs.git
cd go-cqrs
go install ./tools/gen-handler-registry
```

## Usage

1. Navigate to your project root directory (where your `go.mod` file is located)
2. Run the tool:
```bash
gen-handler-registry
```

The tool will:
1. Automatically find your `handlers` directory (case-insensitive)
2. Scan all Go files for handler structs
3. Generate a `registry_gen.go` file with registration calls
4. Determine the correct import paths automatically

## Example Output

Given handlers like:
```go
type CreateUserCommandHandler struct{}
type GetUserQueryHandler struct{}
type UserCreatedEventHandler struct{}
type CreateUserValidator struct{}
```

The tool generates:
```go
// Code generated by gen-handler-registry. DO NOT EDIT.

package main

import (
	"github.com/kmdeveloping/go-cqrs/cqrs"
	"your-module/handlers"
)

func registerHandlers() {
	// Register handlers
	cqrs.RegisterCommandHandler(&handlers.CreateUserCommandHandler{})
	cqrs.RegisterQueryHandler(&handlers.GetUserQueryHandler{})
	cqrs.RegisterEventHandler(&handlers.UserCreatedEventHandler{})
	cqrs.RegisterValidator(&handlers.CreateUserValidator{})
}
```

## Requirements

- Go 1.18+
- A `go.mod` file in your project root
- A `handlers` directory containing your handler structs
- Handler structs must follow the naming conventions (end with `CommandHandler`, `QueryHandler`, `EventHandler`, or `Validator`)

## How It Works

1. **Project Discovery**: Finds your project root by locating the `go.mod` file
2. **Module Path Detection**: Reads the module path from `go.mod`
3. **Handler Directory Location**: Searches for a directory named "handlers" (case-insensitive)
4. **AST Parsing**: Parses Go files to find struct declarations matching handler patterns
5. **Code Generation**: Creates registration code with proper imports and type-specific registration calls

## Integration

After running the tool, make sure to call the generated `registerHandlers()` function in your application startup:

```go
func main() {
    // Initialize your application
    registerHandlers() // Call the generated function
    // Start your application
}
```
